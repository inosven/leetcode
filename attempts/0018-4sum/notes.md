# LC 18 4Sum

## 2026-11-17 · A · 10min

- 一遍过，与暴力对拍 3000 组随机输入一致。固定 i、j + 双指针；同层去重 `i > 0` / `j > i+1`；命中后先移动再和刚用过的（`left-1`/`right+1`）比。
- 追问：在 `remain` 和 `while` 之间能否提前 break？只比 `nums[j+1]` 不对（有负数）。反例 `nums[j+1..] = [-5, -1]`, `remain = -6`：`-6 < -5` 会 break，但 `-5 + -1 = -6` 有解。
- 正确剪枝：`nums[j+1] + nums[j+2] > remain` → `break`（j 变大时 remain 变小、最小和变大，只会更差）；`nums[n-2] + nums[n-1] < remain` → `continue`（j 变大后可能够）。i 层同理用三数最小/最大和。
- 口诀：剪枝用最小和、最大和来判断；条件随循环变大只会更差，才能 `break`。
