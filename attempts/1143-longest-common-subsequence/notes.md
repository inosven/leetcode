# LC 1143 Longest Common Subsequence

## 2026-11-17 · C · 15min

- 层级：定义错，和 11-14 第一次做时同一个老问题：不相等时回头比较前一个字符并 +1（重复计数）。
- elif 分支：`text2[j-2]` / `text1[i-2]` 在 j=1 / i=1 时是 `[-1]`，绕到末尾字符；即使下标合法，前一个字符的匹配已算在 `dp[i][j-1]` / `dp[i-1][j]` 里，再 +1 重复计数。反例 `"ab","ba"` → 2，应为 1（dp[1][1] 就错成 1）。
- else 分支：`dp[i-1][j-1]` 同时丢掉两个字符，丢信息。反例 `"abc","a"` → 0，应为 1。
- 注释写成 "text1 0-j / text2 0-j"，应为 text1 前 i 个 / text2 前 j 个。
- 修改：不相等 → `max(dp[i-1][j], dp[i][j-1])`，删掉 elif。
- invariant：dp[i][j] = text1[:i] 与 text2[:j] 的 LCS 长度；末尾不等时至少一个不在 LCS 末尾，丢一个取 max；+1 只在相等分支。
- 口诀：不相等就丢掉一个，丢 text1 的或者丢 text2 的，取 max；+1 只在相等的分支。

## 2026-11-19 · A · 5min

- 一遍对。不相等分支只取 `max(dp[i][j-1], dp[i-1][j])`，11-14 / 11-17 两次的"回头比较前一个字符再 +1"没有再犯。
