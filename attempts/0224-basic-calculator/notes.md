# LC 224 Basic Calculator

## 2026-11-17 · C · 30min（三版）

**第 1 版：思路错**
- 把 150 的后缀做法（遇运算符弹两个数）套到中缀：`"1+2"` 读到 `+` 时右操作数 2 还没读到。
- 收集到第一个 `)` 为止，`"(1+(2+3))"` 嵌套被切断。
- 栈里存 str（第 4 次「栈里放错东西」）；多位数被拆开；代码本身跑不起来（`while stack` 不进、`i` 未初始化、缩进错）。
- 信号 → 方法：只有 `+ -` 和括号 → 括号只影响符号 → `res` / `sign` + 栈存进括号前的现场（见 `solutions/.../sign-stack.py`，参考答案）。
- 口诀：遇到括号就存现场，遇到右括号就恢复现场再合并。

**第 2 版：改用双栈（数字栈 + 运算符栈 + 优先级），实现错**
- Bug 1：`for i,c in enumerate(s)` 里 `i+=1` 无效，下一轮被 enumerate 覆盖。`"12-3"` → 读 12 后又读 2。翻译 C++ `for (; cond; i++)` 时踩的坑。
- Bug 2：`s.strip()` 只去首尾空格，中间 `' '` 进 else → `priority[' ']` KeyError。
- Bug 3：`op.append(c)` 应为 `st_op.append(c)`（变量名混淆）。
- 口诀：循环里要自己跳 `i`，就用 `while`，别用 `for`。

**第 3 版**：改成 while + st_op，只剩 Bug 2；改 `s = s.replace(' ', '')` 后通过。

- 双栈法加上 `*` `/` 分支（除法 `int(a / b)` 向 0 截断）即可解 772。
