# LC 695 Max Area of Island

## 2026-11-19 · B · 15min

- 层级：实现错。`visited` 从没设成 True，格子被反复压栈 → 死循环。反例 [[1,1]]。
- 修改：起点和邻居在压栈的同时标 visited。
- invariant：每格最多压栈一次，压栈那一刻计入面积 → 必须压栈时标记（pop 时标会重复计数）。
- 口诀：在哪里计数，就在哪里标记。
- 复杂度：O(mn) / O(mn)。
- 改进：名叫 bfs 实为 DFS（栈 + pop 尾部）；开头的 if 多余且条件不成立时 area 未定义；可改 grid 置 0 省 visited。
- 追问：递归版用返回值后序汇总（每格汇总一次，不是"最后一格"才汇总）；area 当 int 参数传不回来，要么返回值要么 nonlocal + 每个岛前重置；递归深度可达 m*n。
