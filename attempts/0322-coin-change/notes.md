# LC 322 Coin Change

## 2026-11-20 · B · 15min

- 层级：定义错。用 -1 表示"凑不出"，但转移是 min，-1 永远被选中；-1+1=0 还会变成"0 个就能凑出"。
- 反例 coins=[2], amount=2：dp[1][2] = min(1, dp[0][2]=-1) = -1，应为 1。
- 修改：初始化 INF，最后 INF → -1。转移 dp[i][j-c]（同一行）本来就对，是完全背包。
- 口诀：求 min 用 INF 当"不可能"，求 max 用 -INF；题目要的 -1 最后再转换。
- 复杂度：O(n·amount) / O(n·amount)；改进为 1D O(amount)，j 正序（0/1 背包倒序，完全背包正序）。
